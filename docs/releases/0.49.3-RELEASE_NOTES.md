# CombatSolver 0.49.3

## 简体中文

相对于 0.49.2 的更新：

- 按实际战斗修改判断第三方 Mod 的兼容性。仅调整商店删牌价格、地图、事件、休息处等战斗外内容时可以正常求解，包括只启用删牌价格修改的 BetterVanillaSTS2。未适配的战斗内容、原版战斗数值和效果修改仍会停止求解并提示来源；Mod 的玩法影响声明也按实际战斗内容核对。

## English

Changes since 0.49.2:

- Third-party mod compatibility is now checked against actual combat changes. Mods that only change shop card-removal prices, maps, events or rest sites can be used with the solver, including BetterVanillaSTS2 with only card-removal price changes enabled. Unsupported combat content and changes to vanilla combat values or effects still stop solving and identify the source. A mod's gameplay declaration is checked against its actual combat content.
