# CombatSolver 0.49.3

## 简体中文

相对于 0.49.2 的更新：

- 收窄第三方 Mod 的兼容性拦截范围。仅调整商店删牌价格、地图、事件、休息处等战斗外内容的 Mod 可以正常求解；遇到未适配的战斗内容时，继续提示所属 Mod 并停止求解。BaseLib、RitsuLib 保持已有支持。

兼容范围说明：仅新增怪物，且本场没有遇到该怪物或受到该 Mod 其他战斗修改影响时，可以正常求解。部分 Mod 关闭功能后仍保留战斗补丁，这类情况目前仍可能提示未适配。

## English

Changes since 0.49.2:

- Narrowed compatibility blocking for third-party mods. Mods that only change shop card-removal prices, maps, events or rest sites can be used with the solver. Unsupported combat content still stops solving and identifies the mod. Existing support for BaseLib and RitsuLib is preserved.

Compatibility scope: a mod that only adds monsters can be used when none of those monsters appears in the current battle and no other combat changes from that mod affect it. Some mods keep combat patches installed even when their features are disabled; these cases may still be reported as unsupported.
