# CombatSolver 0.49.3

## 简体中文

相对于 0.49.2 的更新：

- 第三方 Mod 通过现有战斗适配规则判断兼容性。仅调整商店删牌价格、地图、事件、休息处等战斗外内容时可以正常求解；BaseLib、RitsuLib 沿用已有支持。实际遇到未适配的战斗内容时，继续停止求解并提示来源。

## English

Changes since 0.49.2:

- Third-party mods use the existing combat support rules to determine compatibility. Mods that only change shop card-removal prices, maps, events or rest sites can be used with the solver. Existing support for BaseLib and RitsuLib is preserved. Encountering unsupported combat content still stops solving and identifies the source.
