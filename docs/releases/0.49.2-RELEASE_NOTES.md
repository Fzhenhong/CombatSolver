# CombatSolver 0.49.2

## 简体中文

相对于 0.49.1 的更新：

- 遇到尚未适配的第三方内容效果时，提示“求解器暂未适配此内容性 Mod：名称，无法求解。”，显示所属 Mod 名称，并停止求解；这类问题不再引导上传日志。
- 平台接口错误按实际计算失败分类，并保留问题包上传提示，便于排查。

## English

Changes since 0.49.1:

- When an unsupported third-party content effect prevents solving, the message identifies its mod and states that the solver does not yet support it. These failures no longer prompt players to upload logs.
- Platform API failures are classified as calculation failures and retain diagnostic upload prompts to aid investigation.
