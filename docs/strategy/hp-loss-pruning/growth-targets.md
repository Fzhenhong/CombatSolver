# 各成长目标独立消费战损基准

2026-10-04；第五层补丁基线 `8060330a2`，接在[第四层](resource-buckets.md)之后；源码归档 `05-growth-targets.patch`。适配 CombatSolver 0.49.1 / 游戏 0.111.0。

## 目标与实现

用户目标是成长1次的路线用1次桶的最好战损互剪，成长2次的路线用2次桶的最好战损互剪，不必先找到零战损。桶仍按各来源次数向量区分，药水档与失窃量隔离。内部存战略战损；同桶固定额度相抵后等价于比较该桶实际战损。

胜利见证继续立即收紧各桶。共享 Beam 的保路边界读取当前影子状态，认证剩余成长来源，得到已实现次数至最终上界的目标集合。每个目标查自己的见证，将未来回血已预留的物理战损下界扣除该目标额度后比较。达不到更优战损的目标被排除；仍有一个目标未知或可改进就保留公共展开。目标集合不进入模拟状态键，不给每个桶单开一轮搜索，也不增加独立 Beam 席数；每次保路重新判断。有限 Beam 不能称为穷举。

例如1次桶胜利战损15、2次桶胜利战损20：某节点最终战损下界18且可能达到1或2次，1次目标被排除，2次目标继续；若分支已经不可能再成长、最终只能1次，该节点停止。下界30且最终只能1或2次时，两个目标都被排除。

## 门控与取舍

- 保留原最乐观资源桶路径；新增逐成长目标路径仅用于没有遗物目标、没有第三方成长来源的情况。成长与遗物混合目标仍沿第四层路径，不声称已独立枚举全部遗物组合。
- 分支认证沿第四层原版牌组、遗物、能力闭包。未知/未审计来源、回收消耗、附魔、灾厄、待返回牌、第三方回调等继续回退，未来回血和死亡保护沿原下界预留。
- DualWield 仍有可用成长复制对象时不认证上界；所有成长对象已经移出可用牌堆或不可回收地消耗后，复制基础攻击不再增加成长次数，可以重新认证。不是宣布所有复制牌有限，也不把开局的不受限标签当作已关闭分支的永久禁令。当前原版闭包实际证明优先；原最乐观根路径的门控不变。
- 未终局、无风险、药水档已封闭才消费界。枚举最多256个成长来源向量；超限整体回退，不截掉高次数目标。
- 缺少任一可能目标的完整胜利见证时保留节点；不凭空给未知桶填战损界。目标集合是保守超集，包含实际不可达到的目标时可能少剪。
- 沿既有用户授权的等值截断：同桶战损下界等于见证也可停止，可能放弃同收益同战损但更早结束的路线。已终局路线不受该裁剪。
